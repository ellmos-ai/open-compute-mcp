1. PRODUCT IDENTITY & MISSION
--------------------------------------------------------------------------------
Current scope (updated 2026-10-12): `open-compute-mcp` is a Node.js npm launcher
that forwards MCP stdio to the separate Python `open-compute` server. npm install,
the default GitHub-based `uvx` bootstrap, and an optional interactive update check
use network access. The child inherits the launching environment and operating-
system privileges. Backend action behavior and the MCP client's approvals are
outside this wrapper's enforcement boundary. See README.md and SECURITY.md.

2. EXAMPLE USE CASES
--------------------------------------------------------------------------------
The launcher may be useful to developers building MCP clients, Windows UI tests,
accessibility workflows, or human-reviewed desktop automation. The Python server
provides the computer-use tools; the client controls approvals and result routing.
These are example audiences, not endorsements or assurances of suitability.

3. IMPLEMENTATION BOUNDARIES
--------------------------------------------------------------------------------
  - Transport: the Node wrapper forwards local MCP stdio; this is not a network filter.
  - Startup: npm and the default uvx command retrieve packages from external services.
  - Process: the Python child inherits environment variables and OS privileges.
  - Desktop: real capture/input requires an interactive Windows desktop on the client host.
  - Policy: the backend implements its own action behavior; the MCP client manages its approvals.
  - Verification: CI tests this Node.js repository, not live desktop or network isolation.

4. RELATED REPOSITORIES
--------------------------------------------------------------------------------
The sibling project list below is a set of repository links, not an integration
or compatibility statement. The Python `open-compute` repository is the backend
that the default launcher command retrieves; all other linked projects remain
separate unless their own documentation says otherwise.
