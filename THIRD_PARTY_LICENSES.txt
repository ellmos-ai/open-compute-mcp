1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

open-compute-mcp is engineered under strict architectural and governance invariants:
100% Local-First, Zero-Egress by default, unprivileged user-mode execution (RunAsInvoker),
and pure offline operation. The launcher acts as a lightweight Node.js stdio JSON-RPC
bridge for the Python open-compute backend engine. Real desktop capture and input
require an interactive local Windows desktop session on the MCP client host. The server
emits 0 telemetry and does not connect to external network endpoints.

All direct runtime and developmental dependencies utilized across open-compute-mcp
are distributed under strictly permissive open-source licenses (MIT and BSD-2-Clause).
There are ZERO GPL, AGPL, LGPL, or viral copyleft constraints, ensuring maximum
portability and compliance for autonomous AI coding agents, enterprise desktop workflows,
and secure local tool-use environments.

3. ZERO-COPYLEFT ISOLATION GUARANTEE & RUNASINVOKER CERTIFICATION
================================================================================

1. Zero-Copyleft Isolation Guarantee:
   No components under GPL, AGPL, LGPL, SSPL, or other reciprocal copyleft licenses
   are bundled, linked, or vendored. The product is 100% compliant with commercial
   and enterprise environments requiring clean MIT / BSD-2-Clause permissive licensing.

2. Unprivileged Execution (RunAsInvoker):
   open-compute-mcp requires no administrative privileges, no daemon services, no root
   credentials, and no kernel-level device drivers. It operates entirely in unprivileged
   user space under standard user profiles.

3. Zero-Egress Perimeter:
   By default, no network traffic is emitted by open-compute-mcp. The launcher communicates
   strictly via standard input and standard output (stdio) JSON-RPC streams.
